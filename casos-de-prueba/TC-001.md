# Caso de Prueba: TC-001 - Agregar al carrito

| Campo / Sección | Detalle |
| :--- | :--- |
| **ID** | `TC-001` |
| **Título** | Agregar un producto al carrito en DemoBlaze |
| **Precondición** | El usuario se encuentra en la página principal de DemoBlaze y visualiza el catálogo de productos. |
| **Datos de prueba** | Producto: "Samsung galaxy s6" |

## Pasos

| Paso | Acción a realizar |
| :---: | :--- |
| **1** | Ir a la página principal de DemoBlaze (`https://www.demoblaze.com`). |
| **2** | Hacer clic sobre el nombre o imagen del producto "Samsung galaxy s6". |
| **3** | Esperar a que cargue la página de detalles del producto. |
| **4** | Hacer clic en el botón "Add to cart". |
| **5** | Aceptar la alerta emergente de confirmación del navegador. |

## Resultado esperado

| Ítem | Resultado Esperado |
| :---: | :--- |
| **1** | El producto se añade correctamente al carrito de compras. |
| **2** | Aparece una alerta emergente con el texto "Product added". |
| **3** | Al navegar a la sección "Cart", el producto aparece listado con su respectivo nombre y precio. |
