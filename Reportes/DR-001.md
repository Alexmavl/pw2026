# Reporte de Defecto: DR-001

**ID:** DR-001  
**Título:** Bloqueo de inicio de sesión sin mensaje amigable ni opción de recuperación para usuario bloqueado  
**Severidad:** Media  
**Prioridad:** Alta  
**Estado:** Abierto (Nuevo)  
**Módulo / Componente:** Autenticación / Login  
**Ambiente:** https://www.saucedemo.com/ (Chromium / Windows 11)  
**Autor:** Marvin Vásquez  

---

### Descripción
Al intentar autenticarse con credenciales válidas correspondientes a un usuario con estado bloqueado (`locked_out_user`), la aplicación deniega el acceso mostrando un mensaje de error genérico en la interfaz sin ofrecer alternativas de soporte o recuperación de cuenta.

---

### Precondiciones
1. Conexión activa a internet.
2. Navegador web compatible abierto en la página de inicio: `https://www.saucedemo.com/`.

---

### Datos de Prueba (Test Data)
* **Username:** `locked_out_user`
* **Password:** `secret_sauce`

---

### Pasos para Reproducir
1. Acceder a `https://www.saucedemo.com/`.
2. Escribir `locked_out_user` en el campo de texto **Username**.
3. Escribir `secret_sauce` en el campo de texto **Password**.
4. Hacer clic sobre el botón **Login**.

---

### Resultado Esperado
El sistema no debe permitir el ingreso al inventario, pero debe presentar una notificación descriptiva con orientación al usuario (ej. enlace a restablecimiento o contacto con soporte) manteniendo el estilo corporativo.

---

### Resultado Obtenido
El sistema muestra un banner de error con el texto:
> `Epic sadface: Sorry, this user has been locked out.`
El formulario permanece bloqueado con iconos de error y sin opciones de navegación.
